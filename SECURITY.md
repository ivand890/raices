# Seguridad

La aplicación estática no necesita secretos ni documentos de identidad. Los respaldos son datos locales privados.

Reporta vulnerabilidades mediante **Security → Report a vulnerability** en GitHub. No publiques tokens, documentos ni respaldos en issues. Si el canal no está disponible, abre un issue sin detalles sensibles solicitando un canal privado.

Incluye versiones afectadas, impacto y reproducción mínima con datos sintéticos. No hay un plazo de respuesta garantizado.

Los respaldos se validan pero no están firmados: XP y resultados no acreditan identidad ni aptitud oficial. Las respuestas están en el código cliente; es una herramienta de estudio, no una plataforma de evaluación segura.
